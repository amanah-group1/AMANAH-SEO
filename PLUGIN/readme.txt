Kerangka menu admin AMANAH SEO untuk pengujian navigasi WordPress. Semua halaman adalah placeholder; tidak ada fitur SEO, AI, ENGINE, pemindaian, perubahan website, atau publikasi yang dijalankan.

== Installation ==
1. Upload folder PLUGIN sebagai folder plugin WordPress bernama amanah-seo, atau salin file amanah-seo.php ke folder plugin tersendiri.
2. Aktifkan AMANAH SEO dari Plugins.
3. Buka menu AMANAH SEO di dashboard WordPress.

== Scope ==
- Satu menu induk AMANAH SEO.
- Dashboard, Website & Workspace, SEO Intelligence, Priorities & Tasks, Execution & Approval, Monitoring & Results, Reports, Settings & Access.
- Placeholder penanda produk terpisah AMANAH SEO AI dan AMANAH SEO ENGINE V2.
- Semua halaman dibatasi ke pengguna dengan capability manage_options.
- Tidak membuat tabel database, opsi, cron, endpoint, koneksi, atau perubahan ke website.

== Development status ==
Navigation shell only. All business features are not implemented.
