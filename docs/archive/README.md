## Catatan audit

Laporan audit historis tetap berada di `docs/audits/` agar jalur bukti audit yang sudah ada tidak berubah. Folder tersebut adalah kumpulan bukti historis, bukan daftar dokumen kebijakan aktif. Laporan audit tidak otomatis membuktikan keadaan runtime terkini.

## Aturan pemeliharaan

1. Perbarui dokumen acuan aktif terlebih dahulu.
2. Jangan menghapus arsip hanya karena statusnya superseded.
3. Jika isi arsip hendak digunakan kembali, tinjau relevansinya dan catat persetujuan/adopsinya pada dokumen aktif.
4. Jangan mengklaim status implementasi, integrasi, atau runtime berdasarkan dokumen historis saja.
